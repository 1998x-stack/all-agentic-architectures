Part 1
Foundational Patterns

Essential building blocks for making a single agent more powerful — from self-critique to tool interaction, adaptive reasoning, and structured planning.

#01 Explore →
Reflection
Critiques and refines its own output in a multi-step internal monologue: produce, evaluate, improve.
High-Quality Code Generation, Complex Summarization
#02 Explore →
Tool Use
Overcomes knowledge cutoffs by autonomously calling external APIs and functions when needed.
Real-time Research Assistants, Enterprise Bots
#03 Explore →
ReAct
Dynamically interleaves reasoning ('thought') and action ('tool use') in an adaptive loop for complex multi-step problems.
Multi-hop Q&A, Web Navigation & Research
#04 Explore →
Planning
Proactively decomposes a complex task into a detailed, step-by-step plan before execution.
Predictable Report Generation, Project Management
Part 2
Multi-Agent Collaboration

How agents work together — specialized teams, smart routing, shared workspaces, and ensemble analysis for more robust and diverse outputs.

#05 Explore →
Multi-Agent Systems
A team of specialized agents collaborates, dividing labor across roles for superior depth, quality, and structure.
Software Dev Pipelines, Creative Brainstorming
#07 Explore →
Blackboard Systems
Agents collaborate opportunistically via a shared central memory, guided by a dynamic controller.
Complex Diagnostics, Dynamic Sense-Making
#11 Explore →
Meta-Controller
A supervisory agent analyzes incoming tasks and routes them to the most appropriate specialist sub-agent.
Multi-Service AI Platforms, Adaptive Assistants
#13 Explore →
Ensemble
Multiple independent agents analyze from different perspectives; an aggregator synthesizes for robust, less biased conclusions.
High-Stakes Decision Support, Fact-Checking
Part 3
Advanced Memory & Reasoning

How agents think more deeply and remember — dual memory systems, graph knowledge bases, and multi-path tree search for complex reasoning.

#08 Explore →
Episodic + Semantic Memory
Dual-memory system: vector store for past conversations (episodic) + graph DB for structured facts (semantic).
Long-Term Personal Assistants, Personalized Tutors
#09 Explore →
Tree of Thoughts (ToT)
Explores multiple reasoning paths in a tree structure, evaluating and pruning branches to find optimal solutions.
Logic Puzzles, Constrained Planning
#12 Explore →
Graph (World-Model Memory)
Stores knowledge as a structured graph of entities and relationships, enabling complex multi-hop reasoning.
Corporate Intelligence, Advanced Research
Part 4
Safety & Reliability

Architectures for trusting agents in production — dry-run harnesses, mental simulation, automatic error recovery, and self-aware limitation modeling.

#06 Explore →
PEV (Plan, Execute, Verify)
A self-correcting loop where a Verifier agent checks each action's outcome, enabling error detection and dynamic recovery.
High-Stakes Automation, Finance, Unreliable Tools
#10 Explore →
Mental Loop (Simulator)
Tests actions in an internal mental model to predict outcomes and assess risk before real-world execution.
Robotics, Financial Trading, Safety-Critical Systems
#14 Explore →
Dry-Run Harness
A proposed action is first simulated and must be approved before live execution — human-in-the-loop safety.
Production Agent Deployment, Debugging
#17 Explore →
Reflexive Metacognitive
An agent with a self-model that reasons about its own capabilities and limitations, escalating to humans when needed.
High-Stakes Advisory (Medical, Legal, Finance)
Part 5
Learning & Adaptation

How agents improve over time and solve problems in novel ways — feedback-driven self-improvement and emergent behavior from simple local rules.

#15 Explore →
RLHF (Self-Improvement)
Output is critiqued by an editor agent; feedback drives iterative revision. High-quality outputs saved for future improvement.
High-Quality Content Generation, Continual Learning
#16 Explore →
Cellular Automata
Many simple, decentralized grid-based agents whose local interactions produce complex emergent global behavior.
Spatial Reasoning, Logistics, Complex System Simulation
