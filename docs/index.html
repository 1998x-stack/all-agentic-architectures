反思模式 Reflection
critique pass
让模型先出一版，再自己挑毛病改掉，把生成拆成 generator + critic + refiner 三步。
#02 探索 →
工具使用 Tool Use
tool interface
把外部 API / 函数挂成结构化工具接口，打破参数知识边界和上下文封闭性。
#03 探索 →
推理与行动循环 ReAct
observation loop
Thought → Action → Observation 循环，上一步观察决定下一步动作。
#04 探索 →
显式规划 Planning
explicit planning
先让模型产出步骤清单，再按清单逐步执行，把控制流做成可审计对象。
第二部分
第二部分：多智能体协作

Agent 如何协作——专业分工、智能路由、共享工作空间、集成分析，产出更稳健多样的结果。

#05 探索 →
多智能体系统 Multi-Agent Systems
role decomposition
把研究员、写作、审阅等角色拆开，用流水线或图把它们串起来。
#07 探索 →
黑板系统 Blackboard Systems
shared workspace
把中间产物写到共享黑板上，controller 根据黑板状态动态调度。
#11 探索 →
元控制器 Meta-Controller
entry routing
在请求入口先分类，把任务路由到最合适的专家子 agent。
#13 探索 →
集成模式 Ensemble
parallel redundancy
同一问题同时交给多个独立 agent 处理，再由 aggregator 融合投票。
第三部分
第三部分：高级记忆与推理

Agent 如何深度思考和记忆——双记忆系统、图知识库、多路径树搜索，实现复杂推理。

#08 探索 →
情景 + 语义双记忆 Episodic + Semantic Memory
long-term memory
把对话片段放进向量库，结构化事实放进图/KV，让系统记得住、查得到。
#09 探索 →
思维树 Tree of Thoughts (ToT)
search tree
展开多条思路形成树，边展开边打分、剪枝，把推理变成搜索。
#12 探索 →
图世界模型记忆 Graph (World-Model Memory)
structured knowledge graph
把知识存成实体-关系图，通过遍历图实现复杂多跳推理。
第四部分
第四部分：安全与可靠性

让 agent 在生产环境中可被信任——预演校验、心智模拟、自动纠错、自我边界建模。

#06 探索 →
计划-执行-验证 PEV (Plan, Execute, Verify)
verification loop
每一步执行完都强制过一次 verifier，失败就重规划。
#10 探索 →
心智循环（模拟器） Mental Loop (Simulator)
counterfactual execution
先在内部世界模型里预演，评估风险收益，再决定是否真执行。
#14 探索 →
预演校验 Dry-Run Harness
side-effect gating
有副作用的动作必须先 dry-run + 审核通过，才允许真实执行。
#17 探索 →
自反式元认知 Reflexive Metacognitive
self-boundary reasoning
系统维护自我模型，知道自己擅长什么，据此选择亲自做、调工具还是交给人。

editor 打分给意见，writer 按意见改稿，高分样本沉淀用于持续改进。
